PV - The Protein Viewer

Live demo Documentation Source code

What it does

PV renders cartoons, ball-and-stick, line, trace, sphere and point representations directly from PDB or mmCIF files, with custom color schemes, selections, and proper order-independent transparency, all at interactive framerates even for large macromolecules.

Use it on your own page

<div id="viewer" style="width: 100%; height: 100%;"></div>
<script src="pv.iife.js"></script>
<script>
  var viewer = pv.Viewer(document.getElementById('viewer'), {
    width: 'auto',
    height: 'auto',
    antialias: true,
    quality: 'high',
  });

  pv.io.fetchCif('https://files.rcsb.org/download/1HBB.cif', function (structure) {
    viewer.cartoon('protein', structure, { color: pv.color.ssSuccession() });
    viewer.autoZoom();
  });
</script>

See the README for build instructions and the full API.

pv is a fork and continuation of pv, originally created by Marco Biasini. WebGL2 is required.
