# Samples

Each sample is a page with a live viewer and the code that makes it. The code is complete apart from the page around it: an element with the id `viewer` and the PV script (see [Getting started](/guide/getting-started)). The structures are downloaded from the RCSB.

The [demo](https://awaterho.github.io/pv/demo/) shows much more: every style and color scheme, structures from the PDB, the AlphaFold DB and ModelArchive, and dropping your own files.
